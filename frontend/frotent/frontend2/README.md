# 按界面整理的前端代码

每个编号目录对应一个用户可访问的界面或流程。目录内的 `app/`、`components/`、`lib/` 和 `styles/` 使用原项目相对路径，方便定位源文件；公共依赖统一放在 `shared/`。

| 目录 | 界面/路由 | 主要内容 |
| --- | --- | --- |
| `01-entry-auth` | `/auth` | 登录入口与品牌组件 |
| `02-entry-onboarding` | `/onboarding` | 建档表单、头像编辑、资料确认 |
| `03-work-map` | `/work-map` | 工作地图、知识图谱、职业匹配与场景 |
| `04-catalog` | `/catalog` | 职业目录浏览 |
| `05-chat` | `/chat` | 对话容器、会话和聊天状态 |
| `06-growth` | `/growth` | 动态画像与岗位推荐 |
| `07-growth-records` | `/growth-records` | 成长记录归档 |
| `08-career-path` | `/path` | 职业路径生成、路线图和技能缺口 |
| `09-actions` | `/actions` | 职场模拟占位界面 |
| `shared` | 全局共享 | 根布局、产品壳、品牌/资料组件、客户端 API、类型和静态资源 |

部分组件会在多个界面复用，因此在对应界面目录保留副本；修改时以仓库根目录源码为准，再同步到整理目录。该目录是按界面查阅用的代码镜像，不替代根目录的构建入口。
