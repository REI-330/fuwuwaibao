# 1. `/onboarding` 简历上传入口页面

## 页面用途

用于用户首次进入系统时建立职业画像。

用户有两种方式：

1. 上传已有简历；
2. 手动填写个人信息。

------

## 代码位置

页面：

```
app\(entry)\onboarding\page.tsx
```

组件：

```
components/entry/profile-form.tsx
```

接口：

```
lib/client/profile-api.ts
```

------

# 页面展示逻辑

页面提供两个入口：

## 上传简历

```tsx
<button
className="featured"
onClick={()=>{
 setEntryMode("resume");
 setView("resume");
}}
>
上传简历
</button>
```

功能：

- 上传 PDF/DOC/DOCX/JPG/PNG；
- 提取教育经历；
- 提取技能；
- 提取项目经历；
- 生成用户画像。

------

## 手动填写

按钮：

```tsx
<button
className="xn-option-footnote"
onClick={()=>{
 setEntryMode("manual");
 setView("form");
}}
>
若无简历，请手动填写信息
</button>
```

点击后进入：

```
components/entry/profile-form.tsx
```

------

# 2. 简历上传接口

## 用户输入

| 字段   | 类型   | 说明     |
| ------ | ------ | -------- |
| file   | File   | 简历文件 |
| source | string | resume   |

支持：

```
PDF
DOC
DOCX
JPG
PNG
```

限制：

```
最大10MB
```

------

# 请求接口

## POST `/api/resumes/extract`

Content-Type:

```
multipart/form-data
```

请求：

```
file:
resume.pdf
```

# 3. 手动信息填写页面

## 页面用途

当用户没有简历或者希望主动填写信息时，通过表单建立初始职业画像。

------

## 页面位置

```
components\entry\profile-form.tsx
```

------

# 页面字段

| 字段        | 类型   | 说明          |
| ----------- | ------ | ------------- |
| identity    | string | 用户阶段      |
| school      | string | 学校          |
| major       | string | 专业          |
| grade       | string | 年级/工作年限 |
| careerStage | string | 当前状态      |
| skills      | string | 技能          |
| experience  | string | 经历          |
| directions  | string | 职业兴趣      |
| location    | string | 城市          |
| question    | string | 当前问题      |
| source      | string | manual        |

------

# 表单示例

```json
{
 "identity":"在校生",

 "school":"浙江大学",

 "major":"自动化",

 "grade":"大三",

 "careerStage":"在校学习",

 "skills":
 "Python,STM32",

 "experience":
 "视觉识别小车项目",

 "directions":
 "嵌入式开发",

 "location":
 "杭州",

 "question":
 "希望确定未来方向",

 "source":
 "manual"
}
```

------

# 提交接口

## PUT `/api/profile`

请求：

```json
{
 "identity":"student",
 "school":"浙江大学",
 "major":"自动化",
 "skills":"Python,STM32",
 "experience":"视觉项目",
 "directions":"嵌入式开发",
 "source":"manual"
}
```

------

# 返回用户画像

```json
{
 "requestId":"uuid",

 "data":{

   "profile":{

    "userId":"user_xxx",

    "status":"draft",

    "identity":"student",

    "skills":[
      {
       "name":"Python",
       "level":"unknown"
      }
    ],

    "experiences":[
      {
       "title":"视觉项目"
      }
    ],

    "source":"manual"

   }

 },

 "error":null
}
```

------

# 画像确认

用户点击：

```
开始提取
```

或：

```
确认并开始探索
```

调用：

```
POST /api/profile/confirm
```

作用：

- 保存最终画像；
- 跳转岗位推荐页面；
- 进入职业成长空间。

------

①点击开始提取，就开始对上传的简历/手动上传的信息进行关键信息提取，生成用户画像
