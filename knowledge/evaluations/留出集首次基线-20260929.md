# 留出集首次基线（2026-09-29）

- 题集：`knowledge/evaluations/questions-holdout.json`（50 题：可回答 35 = zh 14 / xl 21，拒答 15）
- 配置：**已采纳配置** = BM25（术语词典增强）+ 向量（`Qwen3-Embedding-0.6B-onnx-int8`，1024 维）
  归一化后加权融合 `α_bm25=0.35`，融合 **Top-30** 交 LLM 重排（`deepseek-v4.1-flash`），取 Top-3

## 结论

1. **重排是本集唯一的增益来源**：xl 层 12/21 → 16/21（+4 题），zh 层本来就 14/14 已饱和。
   与 C 组「增益来自多路+重排这一层」的结论一致。
2. **术语词典在留出集上没有复现 dev 上的增益**：融合档 26/35 → 26/35（+0 题），
   与 C4 在 dev 上 32/34 → 33/34 的 +1 题同量级——**落在波动内**。
   两档的层级命中完全相同，差异只在排序（命中@1 +0.029、答案段 −2）。
3. **拒答阈值可迁移**：dev 标定的 0.615 在留出集上给出几乎相同的三项指标，
   说明「max 余弦」这个绝对值信号不是 dev 过拟合。
4. 失败的 5 题**全是 xl 层**：`XA04`（职业能力）+ `XB02`/`XB03`/`XB04`/`XB05`（测试自动化）。
   `XB02`–`XB05` 集中落在 S13（pytest 英文文档），是**下一轮跨语言攻坚的首要目标簇**。

## 复跑命令

```bash
set -a; . knowledge/eval/.env; set +a
export TEI_MODEL=Qwen3-Embedding-0.6B-onnx-int8 TEI_EMBED_URL=http://127.0.0.1:8090/v1/embeddings

node knowledge/pipeline/bm25-full.mjs \
  --questions knowledge/evaluations/questions-holdout.json \
  --out knowledge/eval/runs/q1024-holdout-bm25-full.json

.venv/Scripts/python.exe knowledge/eval/query_expansion_experiment.py \
  --questions knowledge/evaluations/questions-holdout.json \
  --bm25-baseline knowledge/eval/runs/q1024-holdout-bm25-full.json \
  --expand-with term-map --tag holdout-termmap --emit-only

.venv/Scripts/python.exe knowledge/eval/run_adopted.py \
  --questions knowledge/evaluations/questions-holdout.json --tag holdout- \
  --alpha 0.35 --do-rerank --rerank-candidates 30 \
  --rerank-cache knowledge/eval/runs/holdout-rerank-cache.json \
  --bm25 knowledge/eval/runs/bm25-full-expanded-holdout-termmap.json

.venv/Scripts/python.exe knowledge/eval/layer_breakdown.py \
  --questions knowledge/evaluations/questions-holdout.json \
  --runs holdout-adopted-a035-topk.json

.venv/Scripts/python.exe knowledge/eval/refusal_eval.py \
  --set knowledge/evaluations/questions-holdout.json --threshold 0.615
```

重排跑一遍约 16 分钟（35 题 × 候选 30，推理模型），缓存 35/35 齐全；缓存齐全后复跑
（去掉 `--do-rerank`）只需约 7 秒。

## 已知限制（写报告必须带上）

- **精确 chunkId 口径系统性低估命中**：语料是 ~1500 字重叠窗口，同一句话有多个 chunkId。
  答案段 50/105 是保守下界，真实覆盖率高于此。详见 `标注修正执行记录-20260928.md` §5。
- **消融对照的局限**：无词典那次的「重排档」复用了同一份重排缓存（picks 由词典增强候选产生），
  所以两次的**重排行完全相同**，只有 **FUSION 行**可比。词典的贡献只能用融合行衡量。
- **分层报数是硬要求**：zh 14 / xl 21，两层的最优通道方向相反，报总分会把效应盖住。
