# 切块参数扩展扫描 + 超范围题的跨语料复核（2026-10-01）

## 一、切块参数：把「按 preview 推出来的 200」改成实测

此前**只扫了工资统计**（六档），结构化专业目录那一档的 200 是 `/chunker/preview` 推出来的，
没有单独扫过（原文：「大典一次导入约十分钟…性价比不高」）。

这次扫了**结构化专业目录**（`moe-majors-2026-structured`，9 道题的 gold 出自它）：

| 块长 | 切出的 chunk 数 | 命中@1 | 命中@10（窗口内） | MRR | 均秩（未命中按 11 计） |
|---|---|---|---|---|---|
| **200（现役）** | 100 | **5/9** | 6/9 | **0.5926** | **4.56** |
| 512（WeKnora 默认） | 100 | 5/9 | 6/9 | 0.5926 | 4.56 |
| 1024 | 100 | 4/9 | 6/9 | 0.4741 | 5.89 |

**怎么读这条结果（别读成「200 优于 512」）**：

* 200 与 512 两档**切出来的 chunk 数完全相同（都是 100）**，各项指标逐位相同 ——
  说明对这份语料而言，**块长上限根本不是生效参数**：一条结构化记录本来就短于 200 字，
  200 和 512 给出的是同一份分区。所以这条只证明「200 没有害」，**不能**证明 200 比 512 好。
* 1024 明显变差（@1 掉到 4/9，MRR 0.4741）—— 这一档把多条记录并进一块，区分度下降。
  所以**上限不能放到 1024 这个量级**，这是本次新增的实测边界。
* 口径边界照旧：临时库里的名次是**同一份文档内部**的名次，没有跨文档竞争；
  选定后的绝对值要在正式库复跑确认。

## 二、超范围题（拒答题）的分数分布：换一个语料复核

此前的结论是「超范围题与可答题的分数不可分，所以检索层无法拒答」，但只在现役库上量过。
这次在**现役库（6 文档 / 2000+ chunk）**与**一个只放一份文档的临时库（100 chunk）**上各量一遍：

| 语料 | 可答题 top-1 分数（min/中位/max，26 题） | 超范围题 top-1 分数（min/中位/max，7 题） | 有没有阈值能分开 |
|---|---|---|---|
| 现役库 | 0.0154 / 0.0163 / 0.0164 | 0.0163 / 0.0164 / 0.0164 | **没有**（区间重叠） |
| 跨语料（单文档临时库） | 0.0131 / 0.0162 / 0.3385 | 0.0131 / 0.0164 / 0.0164 | **没有**（区间重叠） |

两个语料上都是「无可分阈值」，而且现役库里**超范围题的中位分（0.0164）还略高于可答题（0.0163）**。

所以「检索层无法拒答」不是某一个库的偶然；**要拒答必须在检索之外另做一层**
（例如：让模型看到 k 条上下文后自己判断够不够 —— 这在
`回答质量与引用支持-20261001.md` 里量过：7 道超范围题**全部**被模型正确拒答）。

> 注意：这些分数是 **RRF 融合分**（秩驱动），绝对值很小且被压缩，
> 所以「看绝对分数设阈值」这条路本身也不成立。

## 三、复算命令

```bash
export PYTHONIOENCODING=utf-8

# ① 结构化目录的切块 sweep（会自动建/复用临时库；跑完可用 --delete-scratch 清理）
python knowledge-cn/eval/chunking_sweep.py \
  --file moe-majors-2026-structured.jsonl --source moe-majors-2026-structured \
  --sizes 200,512,1024 --modes hybrid \
  --questions knowledge-cn/evaluations/questions-cn-v1.json \
  --out knowledge-cn/evidence/chunking-sweep-moe-structured.json
# 实测耗时约 5 分钟（三档：导入 + 每档 9 题）

# ② 超范围题的跨语料分离性
python knowledge-cn/eval/refusal_separability.py \
  --kb aacc4889-a347-44ea-9dd1-b60ec1917cbb \
  --scratch-kb <任一别的语料库 id，例如单文档临时库> \
  --questions knowledge-cn/evaluations/questions-cn-v1.json \
  --out knowledge-cn/evidence/refusal-separability.json
# 实测：66 次检索，约 12 秒
```
